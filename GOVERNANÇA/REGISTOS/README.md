# Registos de governança

Este diretório guarda artefactos de governança específicos do STOCKS. Não incluir segredos nem dados pessoais desnecessários.

## Estrutura prevista

- `decisoes/` — ADRs e decisões materiais.
- `riscos/` — avaliações, tratamentos e aceitação de risco residual.
- `incidentes/` — incidentes, cronologia, investigação, ações e encerramento.
- `validacoes/` — checklists, resultados de testes e aceitação.
- `releases/` — prontidão, autorização, rollback e revisão pós-implementação.
- `fontes/` — inventários e manifestos de dados não específicos de um único ticker.

Criar registos datados quando ocorrer uma decisão, avaliação, incidente, validação ou release real. Não criar registos vazios que deem a entender que o controlo foi executado. Os subdiretórios podem ser criados quando houver conteúdo operacional a guardar.

## Regras de utilização

1. Priorizar fontes oficiais para confirmar identidade do ativo, documentos regulatórios, eventos societários e dados reportados.
2. Utilizar repositórios internos como fontes de implementação, metodologia, evidências e dados processados; verificar sempre a data e o estado dos processos.
3. Não tratar um repositório de projeto como substituto da fonte primária do dado.
4. Para cada análise individual, copiar para `AÇÕES/<TICKER>/fontes.md` as fontes efetivamente utilizadas, incluindo URL, data de publicação, data de acesso, período coberto e limitações.
5. Distinguir dados oficiais, dados derivados, estimativas e opinião analítica.
6. Não declarar que dados foram validados ou atualizados sem evidência verificável.
7. Este catálogo regista as fontes indicadas pelo responsável do projeto; a inclusão não significa que cada página ou conjunto de dados tenha sido auditado nesta operação.

# Histórico de snapshots — <TICKER>

Guardar nesta pasta um ficheiro por data, usando o padrão AAAA-MM-DD.md. Não sobrescrever snapshots anteriores; correções devem criar novo registo ou explicar explicitamente a alteração.

Cada snapshot deve incluir:
- Ticker e classe confirmados;
- data/hora de referência e timezone;
- período e fonte dos dados;
- estado do verificador de eventos societários;
- factos, cálculos, estimativas e opiniões claramente separados;
- principais indicadores e premissas;
- alterações desde o snapshot anterior;
- limitações e dados ausentes;
- fontes com URLs e datas de acesso;
- próximo passo e critério de conclusão.

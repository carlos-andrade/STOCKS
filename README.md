# STOCKS

Gerenciador, monitoramento e relatórios para investir com sabedoria.

## Governança do projeto

A pasta [`GOVERNANÇA/`](GOVERNAN%C3%87A/README.md) contém a adaptação operacional do sistema mestre [GOVERNANCA](https://github.com/carlos-andrade/GOVERNANCA) para o STOCKS: ciclo de vida, gates, papéis, dados e evidências, risco, segurança, decisões, qualidade, operação, WATCHDOG e matriz de controlos.

**Regra:** a documentação local não equivale a certificação nem prova que controlos técnicos estejam ativos. Verifique o [registo de adoção](GOVERNAN%C3%87A/REGISTRO-ADOCAO.md) e a [matriz de controlos](GOVERNAN%C3%87A/MATRIZ-CONTROLOS.md) antes de declarar implementação ou conformidade.
